# LLMs Lost in Extraction: An Industry Case Study on Object-Centric Processes

## About
This repository contains the supplementary material, including among others the code of the prompts, ground truth, evaluation scripts and results as described in the manuscript <i>LLMs Lost in Extraction: An Industry Case Study on Object-Centric Processes</i> accepted to BPM Workshop Natural Language Processing for Business Process Management (NLP4BPM) 2026.

Source_Document.docx is the original full-length document that describes the system and processes relevant for our use case. In our experiments, we used the text in section 2.1.2.1 (pp. 9-36) as input. The text passages that we labeled as ground truth are marked in yellow. Text pertaining to object types is additionally underlined, and text pertaining to object attributes is in bold. The full list of extracted entities, relations, and attributes can be found in OC_document_extraction_labels.xlsx

The code for the LLM calls is available in python files, and the responses and results in the remaining files, respectively. There is a separate readme-file included for the code.
